Deliberate external boundaries

Codex CLI, Claude Code, or another compatible runtime executes the core lifecycle. Optional providers own added spawning, supervision, messaging, telemetry, and persistent terminal control. Product repositories own credentials, deployment commands, endpoints, and policy adapters. Project OS records and verifies their project-local receipts; it does not duplicate either boundary.
