# Extraction provenance

SISO Project OS was extracted from the operating patterns proven in SISO's protected
`oracle-streaming` repository. That source was inspected read-only. No product implementation,
customer data, generated design corpus, credentials, task history, or run evidence is included.

The extraction kept four general contracts:

- canonical project-local work records, execution packets, and lifecycle receipts;
- a routed documentation spine with provenance, semantic currency, and deterministic discovery;
- a task-linked UI campaign from grounded intent through decision, real-app implementation, and proof;
- executable governance that separates read-only detection from explicit state mutation.

Known source scars were treated as negative requirements. In particular, ID allocation is locked,
full repository-relative paths replace basename joins, and `check` never performs repair, moves,
archive operations, or authored-file rewrites.
