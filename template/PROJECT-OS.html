Ownership boundary

Project OS owns project-local records, evidence, projections, migration contracts, and integrity gates. Agent Base owns spawning, model routing, messaging, telemetry, and terminal control. Product-specific credentials and automation remain project-local adapters.

Do not create parallel task lists, dated status hubs, duplicate engine-local skills, or hand-maintained generated indexes.
