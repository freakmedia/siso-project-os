# Project knowledge spine

This directory is for a deliberately small set of cross-domain contracts, such as:

- repository facts that change rarely;
- edit maps and ownership boundaries;
- safety or compliance rules that bind more than one domain;
- project-wide acceptance gates and runbooks;
- documentation structure rules.

If a document has a clear subsystem owner, put it in `docs/domains/<domain>/` instead. The spine is
not a prestigious location and not a general-purpose catch-all. Its index is a routing projection,
not evidence that the linked claims are true.
