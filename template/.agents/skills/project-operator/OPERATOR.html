Project operator

This is the canonical engine-neutral operating authority. Runtime-mandated Markdown files are thin discovery shims that point here and never copy this contract.

Cold pickup

  1. Read the runtime loader: root AGENTS.md for Codex CLI or root CLAUDE.md for Claude Code, then read PROJECT-OS.html.
  2. Read .agents/project-profile.json and its capability manifests.
  3. Read launcher from .project-os/project.json and append the read-only onboard . --json command contract. Do not assume a global binary.
  4. Select one unblocked canonical task and read its dependencies, acceptance criteria, affected files, evidence, and execution log.
  5. Create or reuse a linked run packet before a substantial execution attempt.

Stop when a required project route fails doctoring. Optional orchestration providers may warn when absent; continue with the current CLI and preserve the same canonical records.

Lifecycle

  • Create and update work through Project OS commands. Canonical task JSON is authority; dashboards and generated HTML are projections.
  • Sprints and runs reference existing task IDs and never create a second backlog.
  • Keep project-specific repeatable behavior under the project-local capability root.
  • Use the current CLI for direct execution. Keep spawning, routing, messaging, telemetry, model, and terminal extensions in declared optional providers.
  • Preserve unrelated dirty work and respect the run packet write fence.

Verify and hand off

  1. Run the closest executable checks named by the task and project configuration.
  2. Run the read-only project-os check . --json command contract.
  3. Attach evidence pointers and truthful verification state to canonical task/run JSON.
  4. Rebuild generated projections only after authored state is correct.
  5. Return a bounded PASS, FAIL, or BLOCKED handoff with exact evidence paths.

Never edit generated state as authority, call an unobserved result proven, or copy an optional provider's implementation into this project.

Runtime compatibility

Project OS records packets and outcomes while Codex CLI, Claude Code, or another compatible agent CLI performs the work. Node.js 20+ is the only required command runtime. A declared provider such as siso-agent-base may add subagents, persistent orchestration, panes, and messaging; missing optional providers produce warnings, not core failures.

The canonical command launcher is machine-readable in .project-os/project.json. Execute its program and argument array directly, then append the command-family arguments. Never convert it into an unquoted shell string.
